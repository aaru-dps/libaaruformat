Regenerate a junk sector from the junk map.

Looks up the given disc byte offset in the junk map, initializes the LFG with the matching entry's seed, advances to the correct stream position, and generates the requested number of bytes.

Parameters
entriesArray of junk entries (sorted by offset).
entry_countNumber of entries.
disc_offsetDisc byte offset of the sector to regenerate.
outputOutput buffer to fill.
lengthNumber of bytes to generate.
Returns
0 on success, -1 if the offset is not in the junk map.
