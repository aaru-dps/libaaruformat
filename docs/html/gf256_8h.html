Multiply-accumulate a region: dst[i] ^= GF_mul(src[i], coeff) for all i.

Uses SIMD acceleration when available (AVX2 > SSSE3 > NEON > scalar). If coeff is 0, this is a no-op. If coeff is 1, this is XOR.
