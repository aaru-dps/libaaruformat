Attempt to recover a data block that failed decompression or CRC verification.

Looks up the block's stripe via the ECMB, reads surviving stripe members + parity, RS-decodes the erased shard, and decompresses the recovered block.

Parameters

block_offsetFile offset of the corrupted block.
offsetSector offset within the block.
dataOutput buffer for the recovered sector.
lengthOutput: bytes written to data.
sector_statusSector status from DDT.
Returns
AARUF_STATUS_OK on success, negative error code on failure.
