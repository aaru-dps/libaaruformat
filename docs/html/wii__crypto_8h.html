typedef struct WiiPartitionRegion WiiPartitionRegion

A Wii partition region entry (in-memory representation).

Stores the physical sector range and AES-128 key for one partition. Physical sector numbers are in 0x8000-byte units.

Encrypt a Wii group (0x8000 bytes) from separate hash_block + data.

The hash block IV is all zeros. The data IV is bytes 0x3D0..0x3DF of the encrypted hash block output (matching Dolphin's VolumeWii::EncryptBlock).

hash_block0x400-byte hash block (plaintext input).
