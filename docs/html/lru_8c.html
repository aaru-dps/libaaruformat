Adds a value to the cache with a uint64_t key, evicting LRU entries if over budget.

Adds a new entry to the cache. If an entry with the same key is already present, its value is freed and replaced. If the cache exceeds its memory budget, the least recently used entries are evicted until it fits again. The entry just inserted is never evicted, so the caller may keep using the pointer it handed over for the remainder of the call.

Parameters
cachePointer to the cache header.
key64-bit integer key to add.
valuePointer to the value to store.
sizeSize in bytes of the memory pointed to by value.
