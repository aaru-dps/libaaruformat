Writes one log line.

Called through the TRACE and FATAL macros in log.h.

The whole line is formatted into a buffer and emitted with a single fwrite(), which stdio locks per call, so lines from concurrent threads do not interleave.

void log_init ( void )
static

Resolves the logging configuration from the environment, exactly once per process.

AARUFORMAT_LOG_LEVEL selects "trace" (default), "fatal" or "none". AARUFORMAT_LOG_FILE names a file to append to; if unset or unopenable, stderr is used.
